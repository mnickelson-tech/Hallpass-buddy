Deploy Free on GitHub Pages (2 Minutes)

This entire application is self-contained inside a single HTML file with zero external database dependencies. Follow these 4 steps to host it free for your classroom or school:

  1. 1

    Save this file as index.html

    Download or copy this code and save it on your computer with the exact filename index.html.

  2. 2

    Create a New GitHub Repository

    Log in to github.com, click + → New repository, name it school-hallpass, keep it Public, and click Create repository.

  3. 3

    Upload index.html

    Click uploading an existing file on your repository page, drag and drop your index.html file, and click Commit changes.

  4. 4

    Enable GitHub Pages

    Go to Settings → Pages in your repository. Under Build and deployment → Branch, select main and /(root), then click Save. Your live kiosk URL (https://username.github.io/school-hallpass/) will appear in ~60 seconds!

Classroom Kiosk Tip: Bookmark your GitHub Pages URL on a classroom Chromebook or iPad, click Kiosk Mode in the top bar, and set a 4-digit Teacher PIN in Settings so students can sign themselves out and back in smoothly.
